# Ecommerce-Business

### End-to-End E-commerce Business Analytics

A complete end-to-end Data Analyst project for a direct-to-consumer e-commerce business using Python, MySQL and Excel. The project demonstrates the complete analytics workflow from raw data processing, database design, SQL analysis and data visualization to business insights, covering revenue trends, category and product performance, customer segmentation (RFM), cohort retention, acquisition-channel ROI and order health.

Data note: the dataset is synthetically generated to model realistic e-commerce behavior (seasonality, repeat purchasing, promo response, regional mix) for demonstration and portfolio purposes.

## Key findings
1. Revenue growth is consistent year-over-year, not just a holiday-season effect.
2. Electronics drives the most revenue, but other categories carry higher margins.
3. A meaningful share of past-frequent customers have gone quiet  a clear re-engagement opportunity.
4. Referral and email marketing outperform paid channels on return on spend.
5. Order cancellations/returns account for a noticeable share of volume, worth addressing directly.
